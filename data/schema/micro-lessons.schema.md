# Schemat: micro-lessons.json

Mikrolekcje do feedu „jak TikTok".

| Pole | Typ | Opis |
|------|-----|------|
| `id` | string | Unikalny identyfikator |
| `subject` | string | `id` przedmiotu |
| `nodeId` | string | `id` węzła grafu wiedzy |
| `durationSec` | number | Sugerowany czas (15–60 s) |
| `hook` | string | Chwytliwy tytuł (pierwsza klatka feedu) |
| `body` | string | Treść lekcji (2–4 zdania) |
| `takeaway` | string | Jedno zdanie do zapamiętania |
| `tags` | string[] | Etykiety tematyczne |
