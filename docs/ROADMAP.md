# 🗺️ Roadmapa

Wizja: poprowadzić ucznia przez **całą ścieżkę edukacji — od 4 klasy do matury i
rynku pracy** — budując po drodze jego cyfrowy model poznawczy. Pełna,
25-warstwowa wizja **EduOS** jest opisana w [`VISION.md`](VISION.md).

## ✅ Etap 1 — MVP: Egzamin ósmoklasisty *(fundament gotowy)*

- [x] Mobile-first PWA + deploy na GitHub Pages
- [x] Otwarta baza wiedzy (graf wiedzy, mikrolekcje, zadania, metadane arkuszy)
- [x] Cyfrowy bliźniak: mastery + typy błędów + radar
- [x] Graf wiedzy z wykrywaniem „korzeni" braków
- [x] Feed mikrolekcji „jak TikTok"
- [x] Symulator przyszłego wyniku
- [x] Nauczyciel AI (offline, na bazie wiedzy)
- [x] RPG: poziomy, XP, klasy, osiągnięcia, ranking
- [x] Wykrywanie wypalenia (AI psycholog nauki)
- [x] Pipeline mobilny (Capacitor) + build APK w CI
- [x] **Spaced repetition (SM-2)** — harmonogram powtórek „na czasie"
- [x] **Adaptacyjny dobór sesji** — powtórki + słabe punkty + odkrywanie nowych tematów
- [x] **Pętle zaangażowania** — questy dzienne, combo z mnożnikiem, waluta + skrzynie, ligi tygodniowe
- [x] **Cele i odliczanie do egzaminu** + dzienny cel XP
- [x] **Tryb egzaminu próbnego (boss)** — test na czas z nagrodą
- [x] **Tryb rodzica** — raport postępów (Warstwa 12)
- [x] **Katalog arkuszy 2019–2025** (główny/dodatkowy/próbne) — metadane + linki
- [ ] Rozbudowa banku zadań do pełnego pokrycia wymagań CKE (cel: 500+ zadań)
- [ ] Analiza częstotliwości typów zadań z arkuszy (Warstwa 10)
- [ ] AI Tutor multimodalny: głos + analiza zdjęcia zeszytu (Warstwy 3–4)

## 🔜 Etap 2 — Pełna szkoła podstawowa (klasy 4–8)

- [ ] Graf wiedzy całej podstawy programowej IV–VIII
- [ ] Treści dla klas 4–7 (nie tylko egzaminacyjne)
- [ ] Ścieżki międzyklasowe (np. ułamki w kl. 5 → procenty w kl. 6)
- [ ] Import wymagań z oficjalnych źródeł (ZPE, MEN) do schematu grafu

## 🎓 Etap 3 — Matura i egzamin zawodowy

- [ ] Matura podstawowa i rozszerzona (graf + zadania)
- [ ] Egzamin zawodowy
- [ ] Lektury, streszczenia, informatory CKE jako węzły wiedzy

## 🏫 Etap 4 — AI School OS

- [ ] Konta i synchronizacja (opcjonalny backend)
- [ ] Role: uczeń · rodzic · nauczyciel · korepetytor · szkoła · dyrektor · samorząd
- [ ] Rankingi szkoły i miasta na żywo, gildie/klasy
- [ ] Nauczyciel AI z prawdziwym LLM: analiza toku rozumowania, OCR zeszytu, tryb głosowy 24/7
- [ ] Dashboard dla nauczyciela: wczesne wykrywanie problemów w całej klasie
